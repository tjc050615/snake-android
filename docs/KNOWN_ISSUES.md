## 填写规则

1. 阶段结束必须更新；阶段中途发现 P0 可随时追加。
2. 每条必须有可复现步骤或明确标注"观察，无稳定复现"并降为 P3。
3. 修复后状态改 `fixed`，**追加**验证记录，不删除原行。
4. P0 不得带入下一阶段；不得静默关闭条目。
5. 与 DECISIONS 冲突的问题，先改 DECISIONS 再修代码，不许反向改文档凑代码。
