# CONTEXT

> 版本：v1.0 ｜ 状态：待复核
> 本文件只定义"做什么、边界在哪、什么算成功"；实现细节见 ARCH.md，数值权威见 DECISIONS.md。
> 冲突时：DECISIONS.md > 本文件 > ARCH.md > ACCEPTANCE.md。

## 1. 一句话目标

用 Python + Kivy 做一个**只横屏**的安卓贪吃蛇：无限地图上，人类和 AI 都能玩、能一键切换；AI 以安全存活优先，有可视化路径，在 8ms 硬超时内给出确定性决策，在无解时退化为最优存活而不是装作不会死。

## 2. 技术栈（锁定，不再讨论）

| 层 | 选型 | 备注 |
|---|---|---|
| 语言 | Python 3 | 打包环境由 python-for-android 提供 |
| UI / 渲染 | **Kivy 2.3.0** | 单一 Canvas 批量绘制，不建大量子 Widget |
| 打包 | **Buildozer** | `buildozer android debug` |
| 底层 | **python-for-android** | `requirements = python3,kivy==2.3.0` |
| 原生桥 | **pyjnius** | 仅用于 DisplayMetrics、安全区、震动、分享、常亮、返回键 |
| 持久化 | 私有目录 `config.json` / `profile.json` | 不申请存储权限 |

**不使用**：任何非 Kivy 的渲染/游戏框架、嵌入式浏览器壳、跨平台 UI 框架、C 扩展（M5 可选，非前置）。

## 3. 范围

### V1 做
无限网格世界 + 相机视口；chunk 流式加载；受控随机墙壁与障碍；人类/AI 双模式；AI 安全策略与路径可视化；完整 UI 与设置；历史/回放/种子；成就；持久化；APK 打包与真机性能验收。

### V1 不做
竖屏；每日挑战；联网/排行/账号；道具与技能系统；多人；广告与内购；自定义皮肤导入；拖拽式回放进度条；存储权限申请。

## 4. 硬约束

| 编号 | 约束 | 权威定义 |
|---|---|---|
| C01 | 仅横屏并锁定，不写任何竖屏布局分支 | D-002 |
| C02 | 无限世界用整数格坐标 (x,y)，允许负坐标，不用浮点格坐标 | D-003 |
| C03 | chunk 32×32；视口 +2 圈预加载，超 3 圈卸载 | D-004 / D-005 |
| C04 | 出生点 (0,0)、初始方向 (1,0)、长度 3；周围 3×3 chunk 无墙无障碍 | D-006 / D-007 |
| C05 | 相机死区 10 格；偏移 = max(0, 10 − 距边缘格数)；x/y 独立 | D-008 / D-011 |
| C06 | 相机滞回 2 格；蛇头距边缘 <3 格硬吸附；dt 指数平滑 | D-009 / D-010 |
| C07 | 摇杆死区 15%（与相机死区是两回事，文案必须区分） | D-012 |
| C08 | `grid_size = max(16, round(32*density))`，整数缩放、像素对齐不模糊 | D-013 |
| C09 | 视口宽高至少 21 格，否则提示或缩格子（禁止静默出界） | D-014 |
| C10 | 逻辑固定 Tick 默认 10 次/秒；调速 0.5x~10x 只改 Tick 间隔 | D-015 / D-016 |
| C11 | AI 单步硬超时 8ms；超时按 上→右→下→左 确定性降级 | D-017 / D-018 |
| C12 | AI 决策在下一逻辑 Tick 生效，不允许当帧改变已提交移动 | D-019 |
| C13 | A* 平局键 (f, h, x, y)；BFS 与 A* 并存 | D-020 |
| C14 | AI 局部搜索半径 min(蛇长+20, 80) 格，数据来自视口+2 圈缓存 | D-021 |
| C15 | 一级校验：模拟吃完后新蛇头可达蛇尾；二级校验：洪水填充面积 > 蛇长+10（**启发式加强，非证明**） | D-022 / D-023 |
| C16 | 无安全路径时跟随蛇尾；跟尾也不可行时取最大化存活方向 | D-024 |
| C17 | 穿墙 = 穿障碍（墙与障碍同类）；撞自身仍死亡 | D-025 |
| C18 | 障碍密度约 5%；chunk 边界整行/整列禁障碍，保证全局连通 | D-026 / D-028 |
| C19 | 受控墙：每 chunk 0~2 条、长 3~8 格、不贴边界、留 1 格通道、局部洪水填充校验、同种子一致 | D-027 / D-029 |
| C20 | 食物每 chunk 维持 3~5 个，被吃后同 chunk 补充 | D-030 |
| C21 | 单帧 16.67ms：渲染≤5 / 逻辑≤2 / AI≤8 / chunk≤3 / 输入≤1；AI 与 chunk 错峰；单帧异步合计 ≤8ms | D-036 |
| C22 | 90~120FPS 是渲染上限目标；架构按 60FPS / 55+FPS 落地；M5 真机实测 | D-037 |
| C23 | 调试面板默认关闭，关闭时零额外开销 | D-039 |
| C24 | 权限仅 VIBRATE；min API 23 / target API 33；持久化只在私有目录 | D-034 / D-035 |
| C25 | 并发只能用 Kivy `Clock` 分片；禁止 threading / concurrent.futures / multiprocessing | D-047 |
| C26 | 降载严格按 5 级顺序；55FPS 为硬底线，不得再降 | D-050 |

> **里程碑适用性**：C18 / C19（障碍 5%、受控随机墙）为 **M2 生效项**；M1 只生成空网格 + 食物，无墙无障（D-053）。chunk 在 M1 仅是预生成与渲染范围，不是物理边界（D-054）。

## 5. 禁止事项

1. **禁止**在未确认的情况下修改 DECISIONS.md 中任一已锁定默认值。
2. **禁止**引入任何非 Kivy 的技术栈、替代框架或前端工程化方案（"换个框架更好"一律不讨论）。
3. **禁止**把 C 扩展 / Cython 作为 M1~M4 的前置条件（只能作为 M5 可选优化项）。
4. **禁止**承诺"绝对不死"或"真机 120FPS 稳定"。
5. **禁止**为 AI 引入离线可解性判定器作为验收前置（M3 验收 = 两级校验 + 构造场景）。
6. **禁止**每帧创建大量临时对象、每帧重建 Widget 树、每帧全量扫描世界。
7. **禁止**用浮点格坐标、用屏幕像素直接当世界坐标、用 `int()` 截断代替取整函数。
8. **禁止**写竖屏分支、申请存储/网络权限、把存档写到公共目录。
9. **禁止**一次性堆全部代码；每个里程碑必须可运行、可验收。
10. **禁止**用"看起来对"代替验收命令。

## 6. 成功标准

- M1~M5 的 ACCEPTANCE 条目全部通过，且每条有可复现命令或明确人工判定依据。
- 中端安卓真机：逻辑 Tick 稳定；帧时间 p95 ≤ 16.67ms；**55+FPS 为最低可接受线**；掉帧率达标；连续 10 分钟无热降频崩溃。
- AI 在构造场景集上：不出现"校验通过后仍立刻死亡"的用例；超时必降级；同种子同种子序列可复现。
- 回放：同种子/同决策序列重放结果与原始对局逐 Tick 一致。
- 打包：一条 `buildozer android debug` 出包，`adb install` 可装可跑，权限仅 VIBRATE。
- 交付物齐全（目录、requirements.txt、buildozer.spec、README、测试、性能记录）。

## 9. 术语

| 术语 | 含义 |
|---|---|
| grid / 格 | 最小逻辑单元，边长 `grid_size` 像素 |
| chunk | 32×32 格的生成与加载单位 |
| 死区 | 相机不响应的中心区域（10 格）；摇杆不响应的半径（15%），二者不同 |
| 滞回 | 退出阈值宽于进入阈值，防抖动（相机 2 格） |
| Tick | 逻辑步进，默认 10 次/秒 |
| 两级校验 | 一级可达性 + 二级空间余量（启发式） |
| 跟尾 | 无安全路径时贴近蛇尾行进，延长存活 |
| 穿墙模式 | 墙/障碍可穿越，自撞仍死 |
